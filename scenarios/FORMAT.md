# Формат сценария туториала

Сценарий — это данные: `meta` (что за ролик, где, звук) + `steps` (список шагов по порядку).
Движок (Playwright + silky) проигрывает шаги сверху вниз, между ними — паузы из самих шагов.
Ритм: **тост появился → пауза на чтение → действие → пауза на восприятие**.
Тосты сменяются через уход/приход (старый уезжает, новый приходит).

## meta

| Поле | Смысл |
|--|--|
| `title`, `subtitle` | Текст интро-тайтл-карты |
| `url` | Стартовая страница |
| `readyWhen` | Условие полной загрузки перед сценами (`{text:"..."}` или CSS-селектор) |
| `hide` | Массив CSS-селекторов, которые скрыть при записи (напр. `["app-monitoring-widget"]`) |
| `auth` | Авторизация: `{type:"state"\|"token"\|"cdp"\|"none", …}` — 4 стратегии, см. README |
| `music` | `{file, start, vol}` — фоновый трек (файл, старт внутри трека сек, громкость 0..1) |
| `sfx` | `{click, key}` — файлы-семплы клика и клавиши |
| `voice` | Дикторская озвучка (см. ниже). Нет поля — ролик без голоса, как раньше |
| `out` | Путь итогового mp4 |

## meta.voice — озвучка

Достаточно добавить `"voice": {}` — и весь текст шагов будет прочитан вслух голосом по умолчанию.

| Поле | По умолчанию | Смысл |
|--|--|--|
| `name` | `ru-RU-SvetlanaNeural` | Голос. Список: `silky voices ru-RU` |
| `rate` | `+0%` | Темп речи, напр. `+10%` |
| `pitch` | `+0Hz` | Высота голоса |
| `gain` | `+0%` | Громкость самого синтеза |
| `vol` | `1` | Громкость дорожки голоса в миксе (0..1) |
| `duck` | `0.25` | До какой доли приглушается музыка под голосом |
| `ramp` | `300` | Мс на приглушение музыки и возврат |
| `lead` | `150` | Мс тишины перед репликой |
| `pad` | `400` | Мс тишины после реплики |
| `cache` | `voice` | Папка кэша озвучки |
| `timeout` | `15000` | Мс на синтез одной реплики |

**Что произносится.** Озвучивается `text` шага — у `caption`, `title`, `outro` и `say`.
Поле `say` это переопределяет: `"say": "полная фраза"` — прочитать другое, `"say": false` — промолчать.
Так на экране остаётся короткая подпись, а в наушниках звучит нормальное предложение:

```json
{ "type": "caption", "text": "Открываем статью", "read": 2000,
  "say": "Нажимаем Enter, чтобы открыть статью." }
```

`say` работает на **любом** шаге, не только текстовом — можно комментировать клик или прокрутку:

```json
{ "type": "click", "target": "button.save", "say": "Нажимаем «Сохранить»." }
```

**Тайминг подстраивается сам.** Длительность речи известна до записи, поэтому шаг не заканчивается
раньше, чем диктор договорит, а `hold` у `title`, `outro`, `zoom` и `hover` растягивается под реплику.
Значения `read` / `hold` в сценарии работают как **минимум**, а не как точная длительность —
подписи больше не уезжают на полуслове.

**Кэш.** Каждая реплика синтезируется один раз и лежит в папке `voice/`. Повторная запись
того же сценария голос заново не запрашивает — она быстрее и не требует интернета.
Изменили текст или голос — пересинтезируется только изменившееся.

## step — типы шагов

Каждый шаг: `{ type, ...параметры, after }`. `after` — пауза после шага (мс).

| type | Параметры | Что делает |
|--|--|--|
| `title` | `text, sub, hold` | Интро-карта на весь экран |
| `caption` | `text, read` | Тост снизу; держится `read` мс, потом уезжает |
| `move` | `target, dur` | Плавно ведёт курсор к элементу (наведение) |
| `click` | `target, move` | Курсор к элементу + клик (со звуком клика) |
| `type` | `target, text, cps` | Печатает в поле (со звуком клавиш); `cps` — символов/сек |
| `key` | `key` | Нажать клавишу (напр. `Enter`) — отправить форму / перейти на страницу |
| `zoom` | `target, scale, hold` | Зум-камера к элементу, держит `hold`, возвращает |
| `scroll` | `target` | Плавный скролл элемента в вид |
| `hover` | `target, zoom, hold` | Наводит курсор на элемент (+ опц. зум), держит — «показать явно» |
| `outro` | `text, sub, hold` | Финальная тайтл-карта |
| `say` | `text, hold` | Реплика диктора без подписи на экране (нужен `meta.voice`) |
| `wait` | `ms` | Явная пауза |

## target — как указывать элемент

- `"css-селектор"` — по CSS (первое совпадение). Пример: `'input[placeholder="Поиск"]'`
- `{ "text": "..." }` — найти элемент по тексту (точное/вхождение). Пример: `{text:"Начисление бонусов"}`
- `{ "id": "3522048" }` — строка клиента по внутреннему id (класс `id_...`)
- `{ "css": "input", "index": 0 }` — n-е совпадение CSS

## Пример: демо на Википедии (публичный сайт, без входа)

Готовый файл — `scenarios/wikipedia.json`. Запуск: `node bin/silky.mjs record scenarios/wikipedia.json`.

```json
{
  "meta": {
    "title": "silky-recorder — демо",
    "subtitle": "Пример на Википедии (сайт без входа в аккаунт)",
    "url": "https://ru.wikipedia.org/wiki/Заглавная_страница",
    "readyWhen": "input[name=\"search\"]",
    "auth": { "type": "none" },
    "music": { "file": "assets/music.mp3", "vol": 0.85 },
    "sfx": { "click": "assets/click.wav", "key": "assets/key.wav" },
    "out": "out/wikipedia.mp4"
  },
  "steps": [
    { "type": "title", "text": "Демо silky-recorder", "sub": "Поиск и статья в Википедии", "hold": 3000 },

    { "type": "caption", "text": "Найдём статью через поиск", "read": 2600 },
    { "type": "click",   "target": "input[name=\"search\"]", "move": 1000, "after": 700 },
    { "type": "type",    "target": "input[name=\"search\"]", "text": "Кошка", "cps": 4, "after": 1500 },
    { "type": "caption", "text": "Открываем статью", "read": 2000 },
    { "type": "key",     "key": "Enter", "after": 4000 },

    { "type": "caption", "text": "Вот заголовок статьи", "read": 2600 },
    { "type": "zoom",    "target": "h1", "scale": 1.4, "hold": 3000, "after": 1200 },

    { "type": "caption", "text": "Слева — карточка с фактами", "read": 2600 },
    { "type": "scroll",  "target": ".infobox", "after": 1400 },
    { "type": "zoom",    "target": ".infobox", "scale": 1.3, "hold": 3000, "after": 1200 },

    { "type": "caption", "text": "Пролистаем к разделу", "read": 2400 },
    { "type": "scroll",  "target": { "css": "h2", "index": 1 }, "after": 2600 },

    { "type": "caption", "text": "И наведёмся на ссылку", "read": 2400 },
    { "type": "hover",   "target": { "css": "#bodyContent p a", "index": 1 }, "zoom": 1.6, "hold": 2600, "after": 900 },

    { "type": "outro", "text": "Готово!", "sub": "Так делается любой туториал", "hold": 3000 }
  ]
}
```

> Полный переход по ссылке (здесь — поиск → статья) поддерживается: движок автоматически
> переинжектится на новой странице, курсор/зум/субтитры продолжают работать.

Чтобы заказать новый ролик — достаточно написать такой сценарий. Можно и **не вручную**:
опишите сценарий свободным текстом ИИ-агенту (Claude Code) — в репозитории есть навык
`scenario-author`, который превратит описание в готовый JSON (см. README).
